## The project

The library standardizes authentication across web and mobile projects so teams do not rebuild auth orchestration, state handling, provider configuration, and framework glue for every new product. It is MIT-licensed and open to contributions.

- npm package: [`capacitor-auth-manager`](https://www.npmjs.com/package/capacitor-auth-manager)
- Source: [github.com/aoneahsan/capacitor-auth-manager](https://github.com/aoneahsan/capacitor-auth-manager)
- Issues: [GitHub Issues](https://github.com/aoneahsan/capacitor-auth-manager/issues)
- Docs source: [github.com/aoneahsan/capacitor-auth-manager-docs](https://github.com/aoneahsan/capacitor-auth-manager-docs)
