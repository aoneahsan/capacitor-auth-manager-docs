# Setup, from request to first publish

1. **Request.** Send the form on the [pricing page](/white-label/pricing). We reply by email with the agreement and the payment link.
2. **Names.** Tell us the npm scope and package name, the iOS pod name, the Android namespace and the plugin name you want. If you leave any out, we propose them from your package name.
3. **Access.** Create the npm organization, or pick an existing one, and add our publishing account to it. You keep ownership of the scope.
4. **Brand.** Send your logo as SVG and your brand colors. They go into the README and the docs site.
5. **First build.** We apply the rename to the current release, build it, check the packed tarball and publish it under your scope.
6. **Docs domain.** We send the DNS record for your docs domain. Once it points to us, the docs and the license file go live there.
7. **Active.** The license moves from "being set up" to valid, and the [verify page](/verify-license) shows it.
