Check a Capacitor Auth Manager license

Every licensed build has a key that starts with CAPAUTH-WL-, and its docs domain serves a license file. Check either one here. Verification is run by our licensing service.

What the result means

  • Valid: an active license, and the client it's issued to.
  • Being set up: paid for, with the first build not yet published.
  • Revoked: the license no longer covers this package.
  • Not found: no license has this key, or the domain serves no license file.
