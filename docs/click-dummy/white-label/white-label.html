What changes in your build

Four platforms carry the package's name, so a rebrand touches four places, plus the import line in every app. We make these changes once, then carry them into every release.

The API doesn't change. auth.signIn(AuthProvider.GOOGLE) returns the same credential, and your build has the same providers as the release it's built from. In 3.x that's Google on web, iOS and Android.

  // package.json- "name": "capacitor-auth-manager"+ "name": "@acme/sign-in"  // CapacitorAuthManager.podspec- s.name = 'CapacitorAuthManager'+ s.name = 'AcmeSignIn'  // android/build.gradle- namespace = "com.aoneahsan.capacitor_auth_manager"+ namespace = "com.acme.sign_in"  // src/capacitor-plugin.ts- registerPlugin('CapacitorAuthManager', …)+ registerPlugin('AcmeSignIn', …)  // your app- import { auth, AuthProvider } from 'capacitor-auth-manager';+ import { auth, AuthProvider } from '@acme/sign-in';
